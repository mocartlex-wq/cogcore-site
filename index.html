The core you get

Cognitive Core

Open-source long-term memory and shared workspace for AI agents, exposed over MCP.

  • 5-layer memory, LLM-curated
  • 32 MCP tools: remember, recall, rooms, media
  • Multi-agent rooms with direct messages
  • Multi-tenant, per-tenant storage
  • Docker image, one-line VPS install
  • MIT licence, 1,004 tests, CI with auto-rollback deploy

Cognitive Core consolidates raw events into daily summaries and durable knowledge, with an LLM curator filtering noise at every step. Your agents remember lessons from last month, not every keystroke.

How I work

One engineer, a team of AI agents, tests every night

I set the task and approve the plan; a team of AI agents does the work, in tandem through a shared memory; I review the result and own the handover. You get a person who answers in writing and a test suite that runs while you sleep.

In writing, with a weekly report

Email, Discord or Telegram. Specs, decisions and reports are documents you can search later. I reply within one working day; each week ends with a short written report: what shipped, what is next, what I need from you.

Agents do the typing, I own the result

The agents work as one team with roles, like a small studio: a planner breaks the task into steps, programmers (several Claude Code sessions and Codex) build and fix, a designer (GPT) does the interface and audits, a technician runs servers, deploys and tests, a reviewer (DeepSeek) cross-checks, Alice translates between Russian and English. They work in tandem through a shared memory, Cognitive Core, kept in two places, a local copy on my PC and the memory server, so work continues if either is down. I set the task and approve the plan; the agents do the rest. Every role has its own tools (git and tests for programmers, SSH and Docker for the technician, the browser and Figma for the designer) and gives its own opinion on the task; I weigh all of them together with mine, and only then decide. They consult each other in shared rooms (ask, answer), and each agent reads what the others learned before it starts and writes back its own lessons, so a mistake made once is not made again. The products ship their own agent teams: nine named agents in AI-CRM, a voice assistant, a memory steward. The same team builds and runs those products. The video factory is run by agents end to end: they write the script, generate scenes (Seedance 2.5) and images (Seedream 4.5), voice them (SpeechKit), edit, add music on a local GPU and review every cut; I set the task and approve the plan and the result. I set the architecture and review every change before it lands.

Tests every night

The full suite runs against the current build every night. Your project gets the same loop from day one, with a report that names what passed and what failed.

Handover you can run without me

Every package ends with a runbook for your team: how it is deployed, how to back up and restore, what to do when something breaks, plus a two-hour walkthrough. Everything lives in your git. The 30 days of support after launch are for the questions the runbook did not answer.

FAQ

Questions I get first

Where does my data live, and what leaves my network?

Database, memory service and agent rooms are installed on your infrastructure, so stored data stays there. Two things can leave: requests to the LLM provider you choose for curation and agents, and backups if you point them at external S3-compatible storage. Run a local model and keep backups in-house, and nothing leaves your network. We agree the exact boundary in writing before installation.

Which LLMs can I use?

Cognitive Core talks to agents over MCP, so it works with the clients your team already uses: Claude Code, Claude Desktop, Cursor, ChatGPT. For the model that curates memory you pick the provider. In my own systems I use Claude, OpenAI and DeepSeek models.

You say agents write the code. Who is responsible?

I am. I design the architecture, review every change and sign the handover. The agents are tooling, like a compiler. What you get is a system with a test suite that runs every night, and a person who answers for it in writing.

What if you disappear in six months?

You keep running without me. The software is MIT-licensed and public. The whole deployment is Docker Compose files in your own git. The handover includes a runbook (deploy, back up, restore, what to do when something breaks) and a two-hour walkthrough with your team. If I vanish, you run docker compose up, and any engineer can read the code I would have read.

Cognitive Core is open source. What am I paying for?

Not for the software. For getting it into your environment: integration with your agents and tools, TLS, VPN-only access, backups with a tested restore, the nightly test loop, the runbook, and 30 days of answering questions after launch. A one-line install gets you a demo; the package gets you something your team can own.

How long does it take?

Pilot: two weeks from the day I get server access. Setup: installation plus 30 days of support, with dates fixed before we start. Build: stage by stage, and each stage has its own scope, price and deadline.

How do I pay?

Build is paid per stage, each stage scoped and priced before it starts. Work outside a package is $120 an hour. Invoicing entity, contract and a data-processing agreement are agreed in writing before the first payment.

What do you need from me to start?

SSH access to a server or VM, one integration target, and one person on your side who can answer questions within a day. The pilot starts within a week of that.
