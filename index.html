FAQ

Does my data leave my server?

No. Everything is installed on your infrastructure: database, memory service, agent rooms. The only outbound traffic is to the LLM provider you choose. If you run a local model, nothing leaves your network.

Which LLMs can I use?

Cognitive Core talks to agents over MCP, so it works with the clients your team already uses: Claude Code, Cursor, ChatGPT. For the model that curates memory you pick the provider. In my own systems I use Claude, OpenAI and DeepSeek models.

How long does it take?

Pilot: two weeks. Setup: installation plus 30 days of support, with dates fixed before we start. Build: stage by stage, and each stage has its own scope, price and deadline.
