Cognitive Core

Open-source long-term memory and shared workspace for AI agents, exposed over MCP.

  • 5-layer memory, LLM-curated
  • 32 MCP tools: remember, recall, rooms, media
  • Multi-agent rooms with direct messages
  • Multi-tenant, per-tenant storage
  • Docker image, one-line VPS install
  • MIT licence, 754 tests, CI

Most "AI memory" products are add() and search() on a vector database. Cognitive Core consolidates: raw events become daily summaries, then durable knowledge, with a curator filtering noise at every step.

FAQ

Questions I get first

Does my data leave my server?

No. Everything is installed on your infrastructure: database, memory service, agent rooms. The only outbound traffic is to the LLM provider you choose. If you run a local model, nothing leaves your network.

Which LLMs can I use?

Cognitive Core talks to agents over MCP, so it works with the clients your team already uses: Claude Code, Claude Desktop, Cursor, ChatGPT. For the model that curates memory you pick the provider. In my own systems I use Claude, OpenAI and DeepSeek models.

You say agents write the code. Who is responsible?

I am. I design the architecture, review every change and sign the hand-over. The agents are tooling, like a compiler. What you get is a system with a test suite that runs every night, and a person who answers for it in writing.

How long does it take?

Pilot: two weeks. Setup: installation plus 30 days of support, with dates fixed before we start. Build: stage by stage, and each stage has its own scope, price and deadline.
